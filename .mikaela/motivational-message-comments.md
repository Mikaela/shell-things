# Personal motivational message on shell opening

The motivational message is read by my {zsh,bash}rc if current user is either
aminda or mikaela, or alternatively something hardware specific such as deck.
The reading command is a variation of something like:
`bat --paging=never --language=markdown --force-colorization --style=plain $HOME/.shell-things/.mikaela/motivational-message.md`
`tail -n +1 $HOME/.shell-things/.mikaela/motivational-message.md | grep -v '#'`
Read ../rc/{bash,zsh}rc to find out!

## Why?

I struggle with mental health and invisible disabilities and this is one of my
coping methods trying to remind myself to stay alive and that there is a place
for me somewhere in the world etc. Please don't hurt me.
